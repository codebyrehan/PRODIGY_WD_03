# GharBazaar — Local Store E-commerce Platform

A polished, responsive local-store e-commerce experience built for **Prodigy InfoTech Full-Stack Web Development Internship — Task 03**.

## Highlights
- Product catalogue with images, descriptions, prices and ratings
- Search, category filters and sorting
- Wishlist with persistent browser storage
- Shopping cart with quantity controls and live totals
- Product detail modal
- Checkout interaction placeholder
- Responsive mobile-first layout
- Smooth hover, reveal and drawer interactions
- Accessible labels, semantic sections and empty states
- No paid services or APIs required for the demo

## Tech
HTML5 · CSS3 · Vanilla JavaScript · LocalStorage

## Run
Open `index.html` in a browser or serve the folder with any static web server.
